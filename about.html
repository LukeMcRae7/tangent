01

What it is

tangent is a 3D modeller for Windows & Linux, made for people who design parts to print. It aims for the ergonomics of Blender and the precision of Fusion 360: quick, keyboard-driven modelling with exact geometry, with native export to 3MF and STL.

When an operation would produce something a slicer would reject, tangent refuses it and says why.

02

Why it exists

Artistic modellers are fast but approximate. Engineering CAD is exact but slow to work in, with popular options rarely available to Linux. tangent provides a quick tool that gets the numbers right.

So tangent is built around printing. Holes can be chosen by the screw, with a printer's allowance. Threads are real geometry. Split parts get alignment pins. Every export is checked to be solid before it leaves.

03

Software stack

tangent is C++20 on OpenGL 3.3 with SDL3, targeting Windows and Linux. The geometry comes from OpenCASCADE's boundary representation. Only its modelling libraries are linked. Sketches are solved by planegcs, FreeCAD's constraint solver.

A kernel call that might crash is tried in a separate process first, so a bad operation only shows an error message instead of crashing the app. Every build runs twice, with and without the kernel, along with the test suite and a headless sweep that drives each operation through the real code.

04

“AI slop”

tangent was developed alongside Claude Code, as shown by many of the commits in the repository (including the implementation of this website's design). As a solo developer with a full-time job, creating this project would not be feasible without use of AI tools for much of the tedious work involved in tangent's development.

I generally dislike the idea of "vibe-coded" projects in favor of well-designed, fleshed out products, which is why I attempted to restrict Claude Code usage to backend operation development. I did this by giving it little control of the interface, functionality, and project design. Essentially anything the user interacts with was designed by myself, as well as the project structure and stack decisions.

All AI code is reviewed and tested extensively. Only one agent was ever used at a given time to allow for human supervision and to reserve decision-making to myself.

05

Status

tangent is currently in development and not yet fully functional. Expect rough edges and changes between releases. If you encounter any bugs or would like to request features, please let me know. Contributions are welcome.
